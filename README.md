# 💬 ReactChat – Full Stack Real-Time Chat App

ReactChat is a modern real-time chat application built using Django, Django Channels, and React. It features live WebSocket messaging, user authentication, and a clean, responsive design.

## 🧰 Tech Stack

### Frontend
- **React** (Vite)
- **Tailwind CSS**
- **Axios**

### Backend
- **Django**
- **Django REST Framework**
- **Django Channels (WebSocket)**
- **SQLite3**
